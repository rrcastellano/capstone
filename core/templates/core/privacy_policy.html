2. {% trans "Dados que Coletamos" %}

{% trans "Para fornecer serviços de gerenciamento inteligente de recargas de veículos elétricos, coletamos as seguintes categorias de dados:" %}

  • {% trans "Informações de Conta e Identificação:" %} {% trans "Endereço de e-mail utilizado para criação de conta, autenticação segura e sincronização de dados entre dispositivos." %}

  • {% trans "Dados de Localização:" %} {% trans "Coordenadas geográficas (latitude e longitude) e nome do local do posto de recarga, exclusivamente quando autorizados pelo usuário para mapeamento e registro de estações." %}
